Pasos para desplegar el repositorio del IST Vicente León

Este repositorio es completamente estático y modular, compatible con el tier Hobby 100% gratuito de Vercel y GitHub Pages.
1
Crea un repositorio en GitHub:

Guarda este archivo como index.html y súbelo a un repositorio público o privado en tu cuenta de GitHub.com.

2
Inicia sesión en Vercel:

Accede a Vercel.com con tu usuario de GitHub.

3
Despliegue automático:

Selecciona tu repositorio y haz clic en Deploy. Obtendrás un enlace con HTTPS automático como repositorio-ist-vicenteleon.vercel.app.
